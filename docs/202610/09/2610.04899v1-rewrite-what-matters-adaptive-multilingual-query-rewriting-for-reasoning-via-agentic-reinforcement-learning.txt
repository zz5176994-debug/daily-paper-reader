## ABSTRACT 

In multilingual scenarios, queries with equivalent semantics but in different lan-guages could guide the model into different reasoning trajectories, leading to performance disparities. To mitigate this gap, previous studies typically apply a one-size-fits-all query rewriting strategy, such as translation, which overlooks the fact that different scenarios require diverse types of semantic transforma-tions. In this paper, we propose mRewriter-R1, an agentic multilingual query rewriting framework with reinforcement learning. Unlike single-turn rewriting, mRewriter-R1 formulates multilingual query rewriting as a multi-turn sequential decision-making process, where the model dynamically performs multi-aspect optimization through adaptive operator selection. Experimental results demon-strate that mRewriter-R1 outperforms all strong multilingual rewriting baselines on different large reasoning backbones. Further analyses show that the learned policy can adaptively decide on rewriting operators according to query character-istics, exhibiting strong generalization ability across diverse reasoning tasks, and plug-and-play compatibility with heterogeneous reasoning language models 1.

## 1 INTRODUCTION 

Large Language Models (LLMs) have demonstrated strong capabilities on reasoning. However, their performance has been shown to vary significantly across languages (Huang et al., 2025; Shi et al., 2023). This disparity is caused not only by discrepancies in various language resources but also by a high sensitivity to query understanding. In multilingual settings, queries that are semantically equivalent but differ in syntactic structure and expression across languages could guide the model into different reasoning trajectories, thereby generating inconsistent results (Qi et al., 2025; Huang et al., 2024). Therefore, adequately understanding multilingual queries via essential rewriting can align them with the correct reasoning trajectories so as to leverage the intrinsic reasoning capabilities of LLMs to improve performance for downstream tasks. Existing multilingual query rewriting (MQR) methods primarily rely on empirical manners by applying a one-size-fits-all rewriting strategy to all queries, such as full-sentence translation or word-level translation (Kang et al., 2025; Lu et al., 2024; Yoo et al., 2025). Such strategies cannot consistently achieve satisfactory performance for all queries in diverse scenarios and requirements. As illustrated in Figure 1, prior methods are one-step for a single-aspect, which performs rewriting only once and fails to consider other features that may affect reasoning, such as syntactic structure (Li et al., 2024). For instance, translation helps to understand entities in some queries written in low-resource languages but hurts others that instead only require rewriting the expressions. Thus, an

To address this issue, the query needs to interact with LLMs continuously, leveraging the model’s reasoning process for the query at the current state to determine the most appropriate query rewrit-ing strategy. A promising approach is to employ agentic reinforcement learning (RL) to achieve autonomous query rewriting in dynamic environments (Jin et al., 2025). However, unlike the well-defined decision of retrieval, MQR under agentic RL involves a much more open-ended action space, making stable RL substantially more challenging. It also remains unclear how to effectively integrate MQR into the agentic workflow with RL in rewriting-and-reasoning scenarios. In this paper, we propose mRewriter-R1, an agentic query rewriting framework with RL to solve multilingual reasoning tasks. Instead of relying on static and single-turn approaches, we implement a sequential decision-making paradigm where the LLM acts as both a planner and a rewriter. At each iteration, mRewriter-R1 first generates a plan based on previous turns and then performs query rewriting accordingly. Through multiple iterations, it can learn to autonomously plan the rewriting strategy and rewrite the query, improving the accuracy of the models for the multilingual reasoning. Considering the three essential aspects of a query ( i.e., how to express, how to organize, and what is truly intended ) (Faustini et al., 2023), a single-aspect rewriting strategy is insufficient to simultaneously address the corresponding challenges: eliminating expression discrepancies across languages , constructing well-structured logical forms , and understanding the underlying intent . To alleviate this, we design a multi-aspect query rewriting mechanism driven by specialized operators in a planning space. Specifically, the MQR space is categorized into three aspects: (1) Language aspect, which aims to align queries with high-resource languages via translation-based methods; (2) Structural aspect, which aims to transform complex natural language into well-structured logical expressions; and (3) Semantic aspect, which disambiguates the input and adapts it into a representation that maximizes the utilization of LLMs. Within each aspect, various multilingual rewriting strategies are encapsulated into discrete operators. This formulation constrains the inherently open-ended rewriting decision space to a finite and structured action space, thereby facilitating stable and tractable agentic RL. Subsequently, the model learns to compositionally invoke these operators, achieving combinatorial query optimization tailored to each input. Experimental results on three multilingual benchmarks demonstrate that our mRewriter-R1 framework can improve the performance of multilingual reasoning for various LLMs, consistently outperforming the static application of any single operator across all aspects. 

Our contributions are three-fold: (1) We propose a multi-turn Agentic RL framework that reformu-lates MQR into a sequential decision-making process across multiple aspects, breaking away from empirical rewriting manners. (2) The query rewriter trained by our framework mRewriter-R1 can be deployed as a plug-and-play module for the other LLMs, which is easily adapted with various backbone models and compatible with prompt-based methods such as Chain-of-Thought (CoT). ## 2 METHODS 

As shown in Figure 2, we present the formal framework of mRewriter-R1, an adaptive method designed to systematically rewrite multilingual queries across language, structural, and semantic aspects. The framework follows a multi-turn decision-making manner and is optimized via outcome-based rewards to dynamically employ rewriting operators across multiple aspects. 2.1 AGENTIC WORKFLOW FOR MULTI -T URN DECISION -M AKING 

We formulate MQR as a multi-turn decision-making process, where a single policy model πθ plays two roles at each step. The model first acts as a planner to diagnose the current query and determine how it should be improved, and then acts as a rewriter to produce the updated query. Unlike conventional translation-based preprocessing, our framework allows the model to dynamically determine how the query should be rewritten through multi-aspect rollouts rather than relying on a single static transformation, optimizing multilingual queries in an adaptive and interpretable manner. Formally, this action is serialized with tags: 

pt = ( dt, o t), ot ∈ O dt ,

where ot is the selected operator from the operator set Odt associated with aspect dt.Followed by the action of operator selection, the policy model performs both planning and rewriting in a unified generation process, and the transition of the query from current state to the next is defined by extracting the rewritten query from the generated action: 

at ∼ πθ (· | xt, d t), xt+1 = R(at),

where xt denotes the current state of queries, and R denotes the rewriting operator that transforms the query into the next state. The final rewritten query ˜x is generated before the downstream reasoning process starts, and is fed into a frozen downstream reasoning model after all rewriting steps are completed: 

ˆy = M (˜ x), ˜x = xT +1 ,

where M denotes the downstream LLMs. 2.2 MULTI -A SPECT REWRITING OPERATORS 

As observed in the previous investigation, the failures in multilingual reasoning do not originate from a single factor. In many cases, reasoning errors are not caused by language mismatch alone, but also 3Preprint by implicit structural relations and ambiguous semantic expressions (Qi et al., 2025). Therefore, instead of treating rewriting as a one-step translation problem, we formulate it as a multi-aspect optimization process. However, allowing arbitrary rewriting within a single action space increases the complexity of the optimization process and makes learning more challenging. To alleviate this, we organize the action space into aspect-specific operator sets Odt . At each step, given the current optimization aspect dt, the planner chooses an operator, and then chooses an operator ot ∈ O dt . The theoretical derivation details of the Constrained Operator are in Appendix D. Formally, the rewriting policy can be viewed as a hierarchical decision process: 

πθ (at | xt, d t) = πθ (ot | xt, d t) · πθ (xt+1 | xt, d t, o t).

The first stage determines how the query should be modified, while the second stage generates the rewritten query conditioned on the selected operator. By decomposing reformulation into aspect-specific operator spaces, our framework transforms query rewriting from unconstrained text generation into structured sequential optimization. This not only improves interpretability, but also stabilizes RL by reducing the complexity of the action space. The rewriting aspects are divided into three levels and executed sequentially {d1, d 2, d 3} =

{language , structural , semantics }. This sequential processing manner is designed with the consideration that cross-lingual alignment provides the foundational linguistic space for subsequent structural and semantic optimization, while semantic grounding is most effective after the query structure has been clarified. The specific rewrite spaces of the three aspects are as follows. 

Language-Aspect. The first aspect focuses on cross-lingual alignment. Instead of enforcing full translation for all queries, the model adaptively determines whether the original language should be preserved, translated, or partially rewritten. Representative operators include full translation, bilingual augmentation, and key-term translation. This aspect aims to reduce language distribution mismatch while preserving language-specific information that may benefit reasoning. 

Structural-Aspect. The second aspect focuses on improving the structural organization of the query. Some multilingual reasoning failures arise from important relationships being expressed implicitly or scattered across the query. Therefore, structural-aspect operators reorganize information into reasoning-friendly forms, such as explicitly separating conditions, grouping information by entities, or restating the target question. These operators improve the compositional clarity of the query without changing its semantics. 

Semantic-Aspect. The final aspect focuses on semantic grounding and ambiguity resolution. Even after language and structure are improved, multilingual queries may still contain underspecified references, culturally dependent expressions, or implicit computational targets. Semantic-aspect oper-ators therefore clarify ambiguous references, normalize expressions, and convert implicit reasoning requirements into explicit executable forms while preserving the original intent. 2.3 TRAINING OBJECTIVES AND PROTOCOL 

We train the rewriting policy model πθ using the Group Relative Policy Optimization (GRPO) (Shao et al., 2024), where the objective is not to optimize the downstream model, but to optimize the query rewriting process itself. Specifically, the policy learns to generate rewritten queries that maximize the final reasoning performance of a frozen downstream model using outcome-based reward. 

Outcome-Based Reward. Following recent RL frameworks (Jin et al., 2025), we adopt a simple yet effective outcome-based reward without process supervision. The rewriting policy is rewarded solely according to the final reasoning performance of the downstream model. This design encourages the rewriting policy to discover query transformations that improve downstream reasoning performance, even without explicit supervision on intermediate trajectories. The reward is defined as: 

r(x, ˜x) = Acc( M (˜ x), y ∗),

where y∗ denotes the ground-truth answer and Acc( ·) denotes accuracy after answer normalization.

Prompting and Structured Generation. To stabilize policy learning and enforce interpretable reformulation behaviors, we adopt a structured prompting format during training. The prompt explicitly specifies the current optimization aspect, the allowed operator set, and the required output structure. Importantly, the model is instructed to optimize the query without directly solving the problem. We additionally constrain the reformulation process to preserve all original facts, numbers, and constraints, preventing the policy from introducing hallucinated information during optimization. The full prompting templates and implementation details are provided in Appendix G.

Overall Performance. As shown in Table 1, our method consistently outperforms several strong baselines across various multilingual reasoning benchmarks. Notably, existing MQR approaches apply a fixed rewriting strategy to all inputs, their effectiveness varies substantially across languages and instances. For example, translation-based methods improve performance on some languages but simultaneously degrade others, suggesting that no single rewriting strategy universally fits all multilingual queries. In contrast, mRewriter-R1 alleviates these issues by adaptively selecting suitable rewriting strategies for different multilingual inputs, leading to more robust reasoning performance. In addition, we observe similar improvements on XCOPA and BELEBELE, where our method consistently achieves the best overall performance among all compared approaches. These results suggest that the proposed framework generalizes beyond mathematical reasoning to broader multilingual understanding and commonsense reasoning tasks. 

Plug-and-Play Generalization across Backbone Models. As shown in Figure 3a, to evaluate the generality of the learned rewriting policy, we apply the query rewriter trained by mRewriter-R1 to different downstream backbone models. Experimental results show that our rewriter can function as a plug-and-play module that is easily adapted to off-the-shelf LLMs, improving multilingual reasoning performance across various model families and parameter scales. Across different model scales within the same family, our method substantially enhances multilingual reasoning capabilities in smaller models (3B). More importantly, as the model size increases (32B), our method continues to yield further improvements even when the models already exhibit strong multilingual reasoning capabilities, while other baselines begin to suffer from performance degradation. Moreover, such transferability is particularly important for practical multilingual deployment, where retraining or jointly optimizing large reasoning models is often prohibitively expensive. 

Compatibility with Prompting Strategies. As shown in Figure 3b, we further investigate whether mRewriter-R1 can cooperate with existing reasoning-augmented prompting methods such as CoT. The results show that our framework is complementary rather than competitive to existing prompt-ing paradigms. While CoT primarily improves reasoning decomposition in the generation stage, mRewriter-R1 focuses on optimizing multilingual query understanding before reasoning begins. ## 4 ANALYSIS OF OPERATOR DISTRIBUTION 

To better understand the behavior of the learned rewriting policy, we analyze both the operator selection distribution and the corresponding reasoning performance across different rewriting aspects. Figure 5 presents the usage frequency of operators together with two types of performance compar-isons: (1) the downstream reasoning accuracy on queries where an operator is selected by our policy, and (2) the performance obtained when a single operator is uniformly applied to all queries. 

Comparison of Diverse Operators. First, each rewriting aspect exhibits a dominant operator with substantially higher usage frequency, e.g., full_english_translation in the language aspect, indicating that the policy gradually converges toward several broadly reliable rewriting strategies during RL optimization. Second, several low-frequency operators still achieve high performance on their assigned queries, indicating that the policy learns selective and precise operator-selection behaviors rather than uniformly applying aggressive rewriting strategies. 

Comparison with One-Step. The accuracy on policy-selected queries is consistently higher than the standalone performance of the same operator. These results suggest that rewriting operators are highly context-dependent, and that the key advantage of mRewriter-R1 lies not merely in the operators themselves, but in learning when each operator should be applied. 

Relationship between Distribution and Performance. A comprehensive analysis between distribu-tional behavior and performance shows that operators with stronger standalone performance generally tend to be selected more frequently. For instance, clarify_ambiguous_terms achieves relatively strong standalone performance and is also frequently selected by the policy, indicating that the learned policy can identify operators with broadly transferable utility for multilingual reasoning. 

## 5 DISCUSSION 

Query-Level Risk Analysis. Beyond aggregate accuracy, we perform a paired query-level analysis to examine both the benefits and potential risks introduced by rewriting. As shown in Figure 6, mRewriter-R1 corrects 402 queries that are incorrectly answered by Direct, while degrading 110 initially correct predictions. Compared with the baseline methods, our rewriting strategy minimizes the fraction of queries that are negatively affected, with the gains from successful corrections outweighing the risk of performance degradation. In contrast, the other two methods introduce more than twice as many incorrect corrections as ours. CSICL also struggles to preserve queries (close to 10%) that are already correct and consistent.

## 6 RELATED WORK 

Existing studies on multilingual reasoning attempt to influence the reasoning trajectory of language models mainly from three perspectives: (1) query transformation methods, which modify the input query through strategies such as translation or code-switching (Kang et al., 2025; Lu et al., 2024; Yoo et al., 2025); (2) prompt-based guidance methods, which improve multilingual reasoning through prompting strategies such as CoT (Koo & Kim, 2025; Tran et al., 2025; Qi et al., 2025; Kang & Kim, 2025); (3) training-time alignment methods, which enhance cross-lingual reasoning consistency by updating model parameters through multilingual instruction tuning or RL (She et al., 2024; Zhu et al., 2024; Li et al., 2025a; Hwang et al., 2025; Fan et al., 2025). Among these directions, query transformation directly intervenes at the input level to reduce cross-lingual misunderstanding and is also compatible with the other branches (Lu et al., 2024). Existing query transformation methods adopt empirical strategies, applying the same rewriting operation to all multilingual queries (Ghosh et al., 2025). Although Kang et al. (2025) introduce the dynamic mechanism, it relies on intermediate feedback, making it difficult to complete query rewriting before reasoning begins. In contrast, we propose a learnable agentic MQR framework that dynamically plans and applies multi-aspect rewriting operators before reasoning begins. Moreover, it is more challenging than monolingual settings (Li et al., 2025b; Ye et al., 2025; Nguyen et al., 2025; Zhu et al., 2025), since the rewriting space becomes much more diverse when handling a larger number of languages. To address this, we decouple the complex rewriting space into multi-aspect following a sequential decision-making paradigm through multi-turn iterations, ensuring stable and effective optimization in rewriting-and-reasoning manners. 

## 7 CONCLUSION 

In this paper, we propose mRewriter-R1, an adaptive MQR framework with RL for multilingual reasoning. By formulating MQR as a multi-turn sequential decision-making process, our method 9Preprint dynamically performs language-, structural-, and semantic-aspect rewriting through adaptive operator selection. Experimental results and further analyses on multilingual reasoning demonstrate that the learned policy can adaptively employ different rewriting operators according to query characteristics, exhibiting competitive performance, strong generalization ability, and plug-and-play compatibility with heterogeneous backbones.

## D CONSTRAINED OPERATOR SPACE FOR STABLE AGENTIC RL 

A key challenge in applying agentic RL to MQR is the inherently open-ended nature of the rewriting space. If the policy is allowed to directly generate an arbitrary rewritten query at each step, the action space grows with the vocabulary and sequence length, making the optimization substantially more difficult than conventional discrete decision-making. More importantly, semantically equivalent queries may correspond to highly diverse surface forms, resulting in a large number of distinct actions that yield similar downstream rewards. This redundancy increases the difficulty of credit assignment and introduces high variance into policy optimization. To address this issue, we constrain the rewriting space with a finite set of semantically motivated rewriting operators. Specifically, we decompose MQR into three aspects, namely language, structural, and semantic rewriting. Each aspect ( d ∈ D ) is associated with a finite operator set ( Od), where each operator corresponds to a predefined class of rewriting behaviors.
