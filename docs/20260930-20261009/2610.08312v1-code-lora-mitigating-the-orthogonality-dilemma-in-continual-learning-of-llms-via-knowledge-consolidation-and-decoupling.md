## 摘要
持续学习（CL）对于大语言模型（LLMs）顺序适应不断演变的任务至关重要。为缓解灾难性遗忘，近期方法采用带正交投影的低秩适配（如 O-LoRA）来隔离任务参数。然而，我们发现这种严格的几何约束会引发“正交性困境”：刚性的参数隔离阻碍了跨语义相关任务的共享表示的迁移与积累。在本工作中，我们提出一种新的无回放方法，称为 Consolidation and Decoupling LoRA（CoDe-LoRA），用于大语言模型的持续学习。CoDe-LoRA 将学习过程分解为整合通用知识和解耦任务特定知识。为此，CoDe-LoRA 采用自适应零空间投影机制和语义路由，以平衡知识积累与任务特定适应。在四个主干网络和三个持续学习基准上的实验结果表明，CoDe-LoRA 取得了最佳平均准确率。代码见 https://github.com/Estrellajer/CoDe-LoRA。

## Abstract
Continual learning (CL) is essential for Large Language Models (LLMs) to sequentially adapt to evolving tasks. To mitigate catastrophic forgetting, recent advances implement low-rank adaptation with orthogonal projections (e.g., O-LoRA) to isolate task parameters. However, we reveal that such strict geometric constraints trigger an "Orthogonality Dilemma": rigid parameter isolation impedes the transfer and accumulation of shared representations across semantically related tasks. In this work, we propose a new replay-free method, called Consolidation and Decoupling LoRA (CoDe-LoRA), for CL of LLMs. CoDe-LoRA disentangles the learning process into Consolidating Universal Knowledge and Decoupling Task-Specific Knowledge. To achieve this, CoDe-LoRA leverages an adaptive null space projection mechanism and semantic routing to balance knowledge accumulation with task-specific adaptation. Experimental results across four backbones and three CL benchmarks show that CoDe-LoRA achieves the best average accuracy. Our code is available at https://github.com/Estrellajer/CoDe-LoRA.

## 1. 论文的核心问题与整体含义

- **研究背景**：持续学习（Continual Learning, CL）要求大语言模型（LLMs）顺序适应不断变化的任务，同时避免灾难性遗忘。参数高效微调（PEFT）方法尤其是 LoRA 降低了适配成本，但直接顺序微调仍会导致严重遗忘。
- **核心问题：正交性困境**：近期方法（如 O-LoRA）通过将每个任务的 LoRA 更新约束到与历史任务子空间正交的子空间，来隔离任务参数、减少干扰。本文指出这种严格的几何约束会带来 **“正交性困境”**：
  - 当任务之间语义相关、最优参数更新本应存在重叠时，强制正交会丢弃这些可共享的更新分量。
  - 论文定义了度量 \(\rho_t = \frac{\|\Delta W^*_t P_{<t}\|_F^2}{\|\Delta W^*_t\|_F^2}\) 来量化任务更新与历史子空间的对齐程度，并说明正交约束会使可行更新丢弃恰好 \(\rho_t\) 比例的能量，任务越相关丢失越多。
- **整体含义**：需要在缓解灾难性遗忘的同时，保留跨相关任务的可迁移表示积累，而不是简单地完全隔离参数。

## 2. 论文提出的方法论

- **总体框架**：CoDe-LoRA 采用双分支结构，构建在冻结骨干 \(\theta_{\text{base}}\) 之上：
  - **Consolidation Branch（Co-LoRA，共享分支）**：负责跨任务积累可迁移的通用表示。
  - **Decoupling Branch（De-LoRA，解耦分支）**：维护一组相互独立的任务特定 LoRA 专家 \(\{\theta_k^{\text{spec}}\}_{k=1}^T\)，捕捉各任务的领域细节。
- **Consolidation Branch 核心技术：零空间投影 + 动态缩放**
  1. 在训练完每个新任务 \(t\) 后，得到共享分支的更新 \(\Delta W_{\text{shared}}^{(t)}\)。
  2. 对历史累积共享权重 \(W_{\text{acc}}^{(t-1)}\) 做 SVD，取其列空间正交基 \(U\)。
  3. 将新更新投影到该列空间的零空间上：\(\Delta W_{\text{null}} = \Delta W_{\text{shared}}^{(t)} - UU^\top \Delta W_{\text{shared}}^{(t)}\)，从而消除与已累积表示的干扰。
  4. 使用动态缩放系数 \(c_t = \sqrt{(t-1)/t}\)、\(s_t = 1/\sqrt{t}\)（满足 \(c_t^2 + s_t^2 = 1\)）合并：\(W_{\text{acc}}^{(t)} = c_t W_{\text{acc}}^{(t-1)} + s_t \Delta W_{\text{null}}\)。
  5. 该更新规则保证参数范数有界（论文命题 1），防止共享分支参数爆炸或漂移。
- **Decoupling Branch 核心技术：原型语义路由**
  - 每个任务仅用 \(N=10\) 个随机样本，通过冻结骨干提取嵌入并取归一化均值，构建任务原型 \(P_k\)。
  - 推理时计算输入嵌入 \(e_x\) 与所有原型之间的余弦相似度，选择最相似的任务专家 \(\theta_{k^*}^{\text{spec}}\)。
  - 由于原型和查询都来自冻结骨干，匹配空间不会随学习过程漂移；且仅存储紧凑统计量而非原始样本，保持无回放。
- **知识整合与回退选择**
  - 定义路由置信度为输入与最优原型的最大余弦相似度。
  - 若置信度超过阈值 \(\tau\)（默认 0.75），使用 Decoupling Branch 的任务专家预测；否则回退到 Consolidation Branch 的共享分支预测。
  - 分类任务还使用 PMI 校准候选标签得分。
- **关键公式与算法流程**（文字概括）：
  - 持续学习任务序列 \(\{T^{(1)}, T^{(2)}, \dots, T^{(T)}\}\)；
  - 对每个任务：初始化新专家为零，共享分支从历史累积状态初始化；联合训练两分支；提取共享分支更新；零空间投影；动态缩放合并；归档专家和原型。
