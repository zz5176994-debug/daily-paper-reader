## 摘要
设计具有高效推理能力的表达性序列层仍是现代机器学习的核心挑战。标准的 softmax 注意力通过丰富的非线性 token 交互实现了出色的序列建模性能，但它需要随序列长度线性增长的关键值缓存，从而限制了其可扩展性。线性注意力能够以恒定的内存占用量进行高效循环计算，但其表达能力的降低通常导致建模性能较差。我们提出了切换线性注意力（SwiLA），一种新型序列层，它在保持线性注意力固定大小循环状态的同时增强表征能力，从而弥合这一差距。我们从测试时回归框架推导出 SwiLA 的循环形式，将状态更新规则表述为线性回归混合模型中的在线期望最大化。在测试时，每个输出维度根据输入在多个线性注意力组件之间动态选择。在联想回忆、上下文语言学习和语言建模基准上，SwiLA 表现出强劲的性能，缩小了与 softmax 注意力的差距，在若干场景中甚至超越了它。

## Abstract
Designing expressive sequence layers with efficient inference remains a central challenge in modern machine learning. Standard softmax attention achieves excellent sequence modeling performance through rich nonlinear token interactions, but it requires a key-value cache that grows linearly with sequence length, limiting its scalability. Linear attention enables efficient recurrent computation with a constant memory footprint, yet its reduced expressivity often yields inferior modeling performance. We introduce Switching Linear Attention (SwiLA), a novel sequence layer that bridges this gap by enhancing representational capacity while retaining the fixed-size recurrent state of linear attention. We derive the SwiLA recurrence from the test-time regression framework, casting the state update rule as online expectation-maximization in a mixture of linear regressions model. At test time, each output dimension dynamically selects among multiple linear attention components based on the input. Across associative recall, in-context language learning, and language modeling benchmarks, SwiLA shows strong performance and narrows the gap to softmax attention, even surpassing it in several settings.

### 1. 核心问题与整体含义

#### 研究动机
现代序列建模面临一个根本性矛盾：

- **Softmax 注意力**（Vaswani et al., 2017）：通过非线性 token 交互实现优秀的序列建模性能，但其 KV 缓存随序列长度线性增长，在长上下文场景中成为严重瓶颈。
- **线性注意力**（Katharopoulos et al., 2020）：通过核特征映射将注意力重构为固定大小的循环状态（O(D²)），实现恒定内存推理，但表达能力显著下降——每次检索只能通过单一线性映射完成，无法捕捉多样的、上下文依赖的检索模式，在关联回忆任务上表现不佳。

#### 核心贡献
论文提出的 **Switching Linear Attention（SwiLA）** 旨在弥合这一差距：在保持线性注意力固定大小循环状态的同时，通过混合线性回归增强表达能力，使得从查询到输出的映射具有非线性特征，类似于 softmax 注意力。SwiLA 的有效混合数随输出维度指数增长（O(J^D)），而状态大小仅多项式增长（O(JD²)）。

### 2. 方法论

#### 理论基础：测试时回归（TTR）框架
SwiLA 从 Wang et al. (2025) 的测试时回归（TTR）框架推导而来。TTR 将关联回忆形式化为两步过程：
- **记忆**：给定键值对序列，拟合一个回归函数 m_t，使 m_t(k_i) ≈ v_i。
- **提取**：给定查询 q_t，输出 o_t = m_t(q_t)。

序列层通过选择**函数类**和**优化算法**来定义。SwiLA 在此框架下选择：
- **函数类**：混合线性回归（mixture of linear regressions）
- **优化算法**：在线期望最大化（online EM）

#### 核心模型

SwiLA 将循环状态划分为 J 个混合组件，每个组件维护自己的线性回归器。每个输出维度 d 独立选择混合组件，其生成模型为：z_td 为隐变量（混合分量标签），π_jd(k_t) 为先验概率，v_td 服从以 w_jd^T k_t 为均值的高斯分布。

该模型的有效混合数随输出维度指数增长为 J^D，但参数量仅随 J·D² 多项式增长，实现了表达力与内存效率的巧妙权衡。

#### 状态更新规则（SwiLA 循环）

更新规则从在线 EM 推导，等价于对边缘对数似然的单步随机梯度上升。对每个混合分量 j 和输出维度 d，状态更新（fast weight update）为：

w_tjd = w_{t−1,jd} + β_tjd · r_tjd · δ_tjd · k_t

其中：
- δ_tjd 为预测误差（prediction error），δ_tjd = v_td − w_{t−1,jd}^T k_t
- r_tjd 为责任度（posterior responsibility），表示第 d 维输出由第 j 个混合分量生成的后验概率
- β_tjd 为学习率（learned）

责任度的计算采用 softmax 形式：r_tjd ∝ π_jd(k_t) · exp(−δ²_tjd/2)，即由先验概率与拟合优度共同决定。

#### 检索（输出）
状态更新完成后，查询 q_t 通过混合线性回归器提取输出：o_td = Σ_j π_jd(q_t) · w_tjd^T q_t。

注意到更新规则使用键侧先验 π_jd(k_t)，而检索使用查询侧先验 π_jd(q_t)，两侧先验均为输入的可学习投影。

#### 扩展一：Temporal SwiLA（时间持续性）

在 vanilla SwiLA 中，混合分配没有跨时间步的持续性。Temporal SwiLA 引入马尔可夫先验的近似，通过运行概率分布维护时间连续性：

- 维护滤波后的后验分布，每一步与新的输入依赖分布做凸组合
- 更新规则：r̄_tjd = (1 − g^q_td) · r̄_{t−1,jd} + g^q_td · π^q_jd(q_t)
- 门控系数 g 为输入的可学习函数，控制新旧分布的混合比例

这使得混合分配可以跨连续时间步持续，适用于上下文持续存在的情形（如同一段落中“Harry”指代同一人）。

#### 扩展二：Gated SwiLA（输入依赖状态衰减）

在 TTR 框架下，状态衰减等价于对快权重的高斯先验正则化。通过对混合权重 w_jd 施加各向同性高斯先验，目标函数增加正则化项，导出带门控的更新规则：

- 门控后计算预测误差的变体（实际使用）：
  w_tjd = α_tjd·w_{t−1,jd} + β_tjd·r⁻_tjd·δ⁻_tjd·k_t，其中 δ⁻_tjd = v_td − α_tjd·w_{t−1,jd}^T k_t

门控系数 α_tjd 为可学习的输入依赖衰减因子。两种门控公式在 J=1 时等价（相差重参数化），但在 J>1 时不同。

#### 负载均衡

为防止专家坍塌（少数组件捕获所有责任质量），SwiLA 采用两种互补策略：

1. **互信息辅助损失**：L_MI = −λ_marg·H_marg + λ_cond·H_cond，其中 H_marg 为时间平均责任度的熵（鼓励平衡利用），H_cond 为每 token 平均熵（鼓励每 token 专业化）。同时应用于键侧和查询侧责任度。
2. **输入依赖噪声注入**：在专家 logit 中加入可学习噪声，训练期间有助于探索。

#### 并行化方案（理论）

SwiLA 的非线性循环理论上可通过并行牛顿迭代并行化。关键洞察是：每次牛顿迭代中 SwiLA 的 Jacobian 具有 I − g·k_t·k_t^T 的秩一扰动结构，与 DeltaNet 的线性循环结构相同，因此可用 DeltaNet 的 chunkwise 并行算法求解。但当前实验仍使用顺序 Triton kernel。

#### 3.2 合成基准

**Context-Dependent Associative Recall (CDAR)**：
- 扩展 Arora et al. (2024a) 的关联回忆任务，同一键在不同上下文下映射到不同值。

#### 3.3 大规模语言模型预训练

### 6. 主要结论与发现

1. **表达能力提升**：在近似 softmax 注意力任务中，SwiLA 在每个状态预算

（B = H×J）下均显著优于 DeltaNet，验证了混合线性回归相对于单线性回归的表达能力提升。该任务直接以近似因果 softmax 注意力为目标，结果说明 SwiLA 在保持固定大小循环状态的同时，能够更好地捕获 softmax 注意力的非线性 token 交互模式。

2. **上下文依赖检索能力**：在 CDAR 任务中，SwiLA 及其 Temporal 变体成功学习了同一键在不同上下文下映射到不同值的关联回忆，而普通 DeltaNet 和单线性注意力机制因表达能力不足而失败。这表明混合线性回归和多组件责任度机制为上下文感知的记忆检索提供了有效归纳偏置。

3. **上下文语言学习（RegBench）**：Temporal SwiLA 在低训练规模（例如 1,000 个 PFA）下表现最佳，说明时间持续性先验有助于从少量序列中快速归纳概率规律。随着训练规模增大，各模型的差距缩小，但 SwiLA 系列仍保持竞争力。

4. **大规模语言模型预训练**：
   - 在 374M 参数、15B tokens 设置下，Gated Temporal SwiLA 在常识推理基准上的平均得分与最佳循环基线（如 Gated DeltaNet-MoM、Hybrid GDN）相当，且明显优于普通 DeltaNet。
   - 在回忆密集型任务（SWDE、FDA、SQuAD、TriviaQA、NQ、DROP）上，Gated Temporal SwiLA 取得了接近或部分超过 Transformer++ 的结果，同时保持了恒定内存推理的优势。
   - Hybrid Temporal SwiLA（在部分层插入 softmax 注意力）进一步提升了整体性能，但纯循环 SwiLA 变体已经在多数回忆任务上证明了其能力。

5. **效率与可扩展性**：吞吐量实验显示，在一定序列长度（如 8K 及以上）后，SwiLA 和 Temporal SwiLA 的训练吞吐量显著超过 Transformer 基线；在推理阶段，SwiLA 变体的吞吐量不随 batch size 增长而下降，峰值内存远低于 Transformer，验证了其在长上下文部署中的实际优势。

6. **消融发现**：
   - 增加专家数量（4 → 16）可以提升性能，但增益递减，且会带来更大的状态和计算开销。
   - 加入负载均衡损失能够明显改善路由健康度（提高利用率熵、降低死专家比例），并在多数下游任务上提升准确率。
   - 时间持续性（Temporal）和门控状态衰减（Gated）对于回忆密集型任务尤其重要，二者组合效果最佳。

综上，SwiLA 通过混合线性回归与在线 EM 推导，在固定大小的循环状态内实现了随输出维度指数增长的有效混合数，从而在不牺牲线性注意力恒定内存特性的前提下，显著提升了表达能力和长上下文回忆性能。

### 7. 局限性与未来工作

1. **预训练规模有限**：本文最大模型仅 374M 参数、训练 15B tokens，尚未在数十亿参数和数百亿 tokens 规模下验证 SwiLA 的可扩展性和性能稳定性。
2. **并行化实现未充分展开**：尽管理论上可利用 DeltaNet 的 chunkwise 并行算法加速，但当前实验仍使用顺序 Triton kernel，实际训练和推理吞吐量可能尚未完全释放潜力。
3. **负载均衡损失超参数敏感**：互信息辅助损失的系数需要手动调节，不同任务和模型规模下最优值可能不同，增加了调参负担。
4. **混合回归假设的适用范围**：SwiLA 的表达能力依赖于输出维度之间共享混合组件，但在输出维度相关性低或需要完全独立路由的场景下，其性能可能受限。
5. **长上下文评估不足**：回忆密集型任务仅截断到 2K tokens，未验证在 16K、32K 或更长上下文上的实际检索能力和数值稳定性。
6. **数据域单一**：语言模型预训练仅使用 FineWeb-Edu 数据，缺少多领域、多语言语料的泛化性验证。

未来工作可关注大规模预训练、高效并行核实现、自适应负载均衡策略，以及将 SwiLA 扩展到视觉、多模态和状态空间模型等更多序列建模领域。
