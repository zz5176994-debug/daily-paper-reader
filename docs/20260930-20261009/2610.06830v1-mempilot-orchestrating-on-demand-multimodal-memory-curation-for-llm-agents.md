## 摘要
记忆已成为LLM智能体生态系统中不可或缺的一部分，支持跨交互的信息保留与复用。然而，现有大多数智能体记忆系统以与查询无关的方式构建记忆，这可能导致不必要的预处理开销，并丢弃事后证明至关重要的细节。最近的研究开始将记忆处理转向运行时自适应，但通常专注于特定操作或固定处理方案，对性能、成本和延迟的灵活控制仍很大程度上未被探索。为应对这一挑战，我们提出MemPilot，一个灵活框架，可在不同的性能-成本-延迟偏好下编排按需记忆整理。具体而言，我们通过强化学习优化多步LLM策略，以迭代地在从查询无关记忆中检索与将原始多模态历史的查询特定整理委托给异构LLM和VLM之间做出选择。该策略联合控制证据数量、整理指令、模型选择和视觉访问，从而实现运行时计算的细粒度分配。为了在相互竞争的目标下优化该策略，我们采用按目标优势解耦，在聚合之前分别估计每个目标的优势。此外，我们引入基于前缀的边际效用估计，以在多步rollout中实现细粒度的贡献分配。在五个多模态智能体记忆基准上的实验表明，在不同的优化偏好下实现了良好的性能-成本-延迟权衡，且偏好扫描产生的权衡前沿比现有权衡感知基线更宽广。

## Abstract
Memory has become integral to the LLM agent ecosystem, supporting information retention and reuse across interactions. However, most existing agent memory systems construct memory in a query-agnostic manner, which can incur unnecessary preprocessing cost and discard details that later prove essential. Recent studies have begun shifting memory processing toward runtime adaptation, but typically specialize in particular operations or fixed processing schemes, leaving flexible control over performance, cost, and latency largely underexplored. To address this challenge, we present \textbf{MemPilot}, a flexible framework that orchestrates on-demand memory curation under different performance--cost--latency preferences. Specifically, we optimize a multi-step LLM policy via reinforcement learning to iteratively choose between retrieving from query-agnostic memory and delegating query-specific curation of raw multimodal history to heterogeneous LLMs and VLMs. The policy jointly controls evidence amount, curation instructions, model selection, and visual access, enabling fine-grained allocation of runtime computation. To optimize this policy under competing objectives, we adapt objective-wise advantage decoupling by separately estimating each objective's advantage before aggregation. Moreover, we introduce prefix-based marginal utility estimation for fine-grained credit assignment across multi-step rollouts. Experiments on five multimodal agent-memory benchmarks demonstrate favorable performance--cost--latency trade-offs across optimization preferences, with preference sweeps yielding broader frontiers than existing trade-off-aware baselines.

## 2. 论文提出的方法论

MemPilot 的核心思路是将按需记忆整理形式化为一个**多步决策过程**，由强化学习优化的策略动态决定每一步是直接检索、还是委托外部模型进行查询特定的原始历史整理。

### 2.1 双视图记忆表示

MemPilot 维护两种互补的交互历史视图：

- **查询无关记忆库 \( M \)**：可以由任意现成的智能体记忆系统初始化，支持高效访问；
- **原始多模态历史 \( H \)**：保留完整的多模态上下文，包括文本和图像。

\( M \) 提供快速检索通道，\( H \) 保留细粒度信息，便于查询特定的深度整理。

### 2.2 多步决策与动作因子化

给定查询 \( q \)，orchestrator 策略 \( \pi_\theta \) 在第 \( t \) 步根据状态 \( s_t=(q,a_{<t},o_{<t}) \) 输出结构化动作：

\[
a_t=(z_t,\phi_t)\sim \pi_\theta(\cdot\mid s_t)
\]

动作类型：

\[
z_t\in\{\text{Retrieve},\text{Curate}\}
\]

- **Retrieve**：直接从记忆库 \( M \) 语义检索；
- **Curate**：对原始历史 \( H \) 进行查询特定整理，并委托给外部 LLM/VLM 处理。

动作参数被分解为多个可控维度：

- Retrieve：`(retrieval_query, evidence_count)`
- Curate：`(retrieval_query, evidence_count, curation_instruction, model, include_images)`

其中：

- `retrieval_query` 与 `curation_instruction` 解耦，避免将“检索什么”和“如何整理”混在一个字段中；
- `model` 从异构模型池中选择；
- `include_images` 决定是否将原始图像证据包含在请求中。

这种因子化使策略可以在证据深度、整理策略、模型容量和模态访问等多个维度上进行细粒度控制，而不依赖固定流水线或预算档位。

### 2.3 异构模型委托

MemPilot 采用类似 LLM routing 的机制，将 `Curate` 操作委托给一个可配置的异构模型池：

- 池中包含不同规模的 LLM 和 VLM；
- orchestrator 收到匿名模型 ID 及轻量特征描述（如参数规模和模态支持）；
- 被选模型 \( m_t \) 根据整理指令处理检索到的证据，并将文本观察结果返回给 orchestrator；
- 视觉能力路线可通过 `include_images` 控制是否输入原始图像。

### 2.4 资源感知奖励建模

策略训练使用 **Group Relative Policy Optimization（GRPO）**，同时优化回答质量、金钱成本和延迟三个目标。

#### 奖励定义

对每条轨迹 \( \tau_i \)：

\[
r_i^Q=Q(\tau_i),\quad r_i^C=-C(\tau_i),\quad r_i^L=-L(\tau_i)
\]

- \( Q(\tau_i) \) 为任务特定的回答质量（如 F1）；
- \( C(\tau_i) \) 包括 orchestrator 生成成本与外部模型调用成本；
- \( L(\tau_i) \) 为延迟代理估计，避免不稳定墙钟测量。

#### 目标级优势解耦（objective-wise advantage decoupling）

先在 rollout 组内对每个目标分别标准化：

\[
A_i^j=\frac{r_i^j-\mu^j}{\sigma^j+\epsilon_{\text{norm}}},\quad j\in\{Q,C,L\}
\]

再按偏好向量 \( \lambda=(\lambda_Q,\lambda_C,\lambda_L) \) 加权聚合：

\[
\bar A_i^\lambda=\lambda_Q A_i^Q+\lambda_C A_i^C+\lambda_L A_i^L
\]

最后在 batch 级别再次标准化，得到用于 GRPO 的优势：

\[
A_i^\lambda=\frac{\bar A_i^\lambda-\mu_{\bar A}}{\sigma_{\bar A}+\epsilon_{\text{norm}}}
\]

#### 基于前缀的边际效用（prefix-based marginal utility）

为解决轨迹级优势无法区分不同整理阶段贡献的问题，在每个阶段 \( t \) 对 rollout 前缀直接生成答案进行探测：

\[
u_{i,t}=Q(\hat y_{i,t}),\quad \Delta u_{i,t}=u_{i,t}-u_{i,t-1}
\]

\( \Delta u_{i,t} \) 估计阶段 \( t \) 对回答质量的边际贡献，然后将该边际效用加入对应阶段的策略 token 优势：

\[
\tilde A_{i,k}=A_i^\lambda+\eta\Delta u_{i,t},\quad k\in S_{i,t}
\]

其中 \( S_{i,t} \) 为该阶段之前策略推理与动作 token 集合，\( \eta \) 控制边际信用强度。由于探测回答较短且共享前缀 KV-cache，额外开销较小。

最终损失为带 KL 正则的 clipped GRPO 损失。

## 6. 主要结论与发现

- **MemPilot 能实现可控的多目标权衡**：Perf 偏好下获得所有 5 个基准上最高的 LLM-judge 分数；Bal 在中等成本下保持较强质量；Cost 大幅降低资源消耗但质量下降。
- **相较基线具有更宽广的权衡前沿**：性能-成本和性能-延迟前沿均包络大部分基线，尤其是 LightMem、BudgetMem、OmniSimpleMem 等权衡感知方法。

- **训练资源未披露**：论文未报告 GPU 型号、数量、总训练时间及算力消耗，影响可复现性与成本评估。
- **缺乏统计显著性检验**：主要结果未给出多次运行的标准差或置信区间，难以判断部分改进是否显著。
- **外部 API 成本波动**：成本对比依赖第三方模型 API 定价，随时间变化可能影响公平性；同时不同模型 tokenizer 差异也可能带来成本归一化误差。
- **单一策略模型**：orchestrator 默认仅使用 Qwen3-4B-Instruct，未探索其他尺寸或架构的策略模型对权衡行为的影响。
- **任务范围有限**：基准集中于多模态长期记忆问答，未来可扩展到更复杂的智能体规划、工具使用和真实世界交互场景。
- **离线训练假设**：当前采用离线 RL 训练，未在部署中持续在线学习，可能限制对动态环境和新型查询的适应能力。

## 8. 总结

MemPilot 提出了一种基于强化学习的运行时多模态记忆编排框架，通过多步决策、动作因子化和异构模型委托，在回答质量、金钱成本和延迟之间实现了灵活且可控的权衡。实验表明，该方法在多个多模态记忆基准上取得了更宽的权衡前沿，并展现出对现成记忆库的兼容性与分布外泛化能力。尽管仍存在延迟代理、资源未披露等局限，MemPilot 为构建资源感知的自适应记忆系统提供了有效思路。
