## 摘要
低秩适配（Low-Rank Adaptation，LoRA）通过将模型更新约束在低秩子空间内实现参数高效微调，并已在实践中广泛使用。然而，LoRA 通常对不同 token 采用共享的低秩更新，这限制了其充分利用来自不同序列的 token 的适配子空间的能力。为解决这一问题，我们提出了一种低秩适配的自适应利用方法（U-LoRA），该方法采用条件门控来显式学习对有限低秩适配子空间的有效 token 级利用。具体而言，U-LoRA 为每个 token 沿低秩方向生成利用系数，并利用序列级上下文信息对其进行联合协调和约束，从而在句子内诱导出更一致的自适应模式。为进一步增强训练稳定性，我们引入了一种经偏差校正的指数滑动平均（EMA）历史先验，用于跨优化步骤校准利用信号，抑制批次间波动引起的噪声。我们方法的有效性源于通过输入条件化策略更好地利用现有低秩子空间，而非扩展子空间。在数学推理和自然语言理解基准上的实验表明，在可比的参数预算下，U-LoRA 与强 LoRA 基线及近期变体相比取得了有竞争力的性能。

## Abstract
Low-Rank Adaptation (LoRA) achieves parameter-efficient fine-tuning by constraining model updates to a low-rank subspace and has been widely used in practice. However, LoRA typically employs a shared low-rank update across tokens, which limits its ability to fully exploit the adaptation subspace for tokens from different sequences. To address this issue, we propose an adaptive utilization of Low-Rank Adaptation (U-LoRA), which employs conditioned gating to explicitly learn effective token-level utilization of the limited low-rank adaptation subspace. Specifically, U-LoRA generates utilization coefficients along low-rank directions for each token and jointly coordinates and constrains them using sequence-level contextual information, thereby inducing more consistent adaptive patterns within a sentence. To further enhance training stability, we introduce a bias-corrected exponential moving average (EMA) historical prior that calibrates utilization signals across optimization steps, suppressing noise caused by batch-to-batch fluctuations. The effectiveness of our method arises from a better utilization of the existing low-rank subspace via input-conditioned strategies, rather than from expanding the subspace. Experiments on mathematical reasoning and natural language understanding benchmarks demonstrate that U-LoRA achieves competitive performance under comparable parameter budgets when with strong LoRA baselines and recent variants.

## 1. 论文的核心问题与整体含义

- **研究背景**：LoRA 通过将权重更新约束为低秩分解 \(W = W_0 + BA\) 实现参数高效微调，已被广泛采用。然而，标准 LoRA 对所有 token 共享同一套低秩基 \(A,B\)，导致不同语义上下文中的 token 被迫使用相似的低秩更新方向，可能产生任务间干扰，限制模型对复杂、上下文敏感行为的建模能力。
- **核心问题**：低秩子空间是有限的，但 LoRA 对其利用是**隐式且近似均匀**的；同一 token（如 “book”）在不同任务/语境下可能需要激活不同的低秩方向，而共享低秩基难以解耦这些任务特定信号。
- **整体含义**：与其扩大低秩子空间（增加 rank 或结构化扩展），不如**更聪明地利用已有低秩容量**。论文从“低秩子空间利用”这一新视角出发，提出显式学习 token 级、上下文一致的低秩方向利用策略。

## 2. 提出的方法论

### 2.1 核心思想

- 在 LoRA 基础上引入**输入条件化门控**，将固定的下投影矩阵 \(A\) 变为与输入相关的 \(A(x)\)：
  \[
  A(x) = G(x) \odot A
  \]
  其中 \(G(x)\) 是与 \(A\) 同形状的门控系数矩阵，通过逐元素乘法控制各低秩方向的激活强度。
- 当 \(G(x)\equiv 1\) 时退化为标准 LoRA；可训练参数为共享低秩基 \(A,B\) 与门控函数 \(G(\cdot)\)，主干权重 \(W_0\) 保持冻结。

### 2.2 Token 级利用与序列级聚合

- **输入投影**：对输入表示 \(X=[x_1,\dots,x_s]\)，先投影到与 rank 对齐的特征空间：
  \[
  F = \text{RMSNorm}(XW_{\text{proj}})
  \]
  其中 \(W_{\text{proj}}\in\mathbb{R}^{d_{\text{in}}\times r}\)，每个 token 得到 \(f_t\in\mathbb{R}^r\)。
- **序列级方向摘要**：沿 rank 维度做 softmax 后加权求和：
  \[
  s = \sum_{t=1}^{s} \text{softmax}(f_t)\odot f_t
  \]
  捕获序列对低秩方向的全局偏好；在 decoder-only 架构中使用 causal mask，保证每个 token 只看前缀。
- **融合形成门控表示**：
  \[
  z_t = f_t + g_{\text{tok}}(f_t) + g_{\text{seq}}(s)
  \]
  其中 \(g_{\text{tok}}, g_{\text{seq}}\) 为可学习线性映射，分别提供 token 级和序列级调制。

### 2.3 历史先验稳定训练

- 对每个 mini-batch 内 \(B\) 条序列的序列摘要求均值：
  \[
  \bar{s}_t = \frac{1}{B}\sum_{i=1}^{B} s^{(i)}
  \]
- 维护 EMA 历史统计量：
  \[
  m_t = \beta m_{t-1} + (1-\beta)\bar{s}_t,\quad \hat{m}_t = \frac{m_t}{1-\beta^t}
  \]
- 将偏差校正后的 \(\hat{m}_t\) 作为历史先验**直接加到**中间门控表示上：
  \[
  G_t(X) = z_t + \hat{m}_t
  \]
  并广播到所有 token，以平滑跨步骤的批次波动噪声。
- 前向更新：
  \[
  h_t = W_0x_t + \gamma \cdot B\left( (G_t(X)\odot A)x_t \right)
  \]
  其中 \(\gamma\) 为低秩分支缩放因子；推理时历史先验冻结，不产生额外更新。

## 6. 主要结论与发现

- **性能结论**：
  - 数学推理：U-LoRA 在 4 个 LLM 上均取得最高平均准确率，且 U-LoRA r=8 常超过 LoRA r=32 或 TopLoRA r=16，表明**利用低秩子空间优于扩大 rank**。
  - GLUE：U-LoRA 在 RoBERTa-Base/Large 上均取得最佳平均分，尤其 CoLA、STS-B 等任务提升明显。
- **消融发现**：
  - Token 级利用（TOK）贡献最大，移除后平均分下降 5.02 点；序列级聚合（SEQ）和 EMA 历史先验（EMA）也各自显著贡献（下降 4.81、4.31 点），三者具有互补性。
- **几何分析**：
  - U-LoRA 在深层形成更紧凑、结构化的任务簇，任务内一致性和任务间语义关系优于 LoRA/TopLoRA。
  - 案例研究表明 U-LoRA 在中间层保留 token 级差异，深层逐渐整合为序列级抽象，呈现“先分离后整合”的模式。
- **效率结论**：
  - U-LoRA 推理延迟略高于 LoRA（约 1.39×），但效率-性能权衡更好：每 0.1× 延迟增益 +1.40，优于 TopLoRA 的 +0.80。
- **总体结论**：U-LoRA 通过输入条件化策略更有效地利用现有低秩子空间，在参数效率与性能之间取得更好平衡，且对大规模和指令微调模型同样有效。

## 7. 优点

- **方法设计合理**：
  - 条件门控逐元素调制 \(A\)，保持低秩结构不破坏 LoRA 的参数效率。
  - 序列级聚合与 token 级信号结合，增强句内一致性。
  - EMA 历史先验简单轻量，有效抑制批次波动，提升训练稳定性。
- **实验扎实**：
  - 覆盖多种模型架构、规模和任务类型，包含消融、扩展、几何可视化、案例分析、延迟分析等多维度验证。
  - 与近期代表性 LoRA 变体充分对比，参数量标注清晰。

## 8. 不足与局限

- **推理效率受限**：
  - 由于 token 级动态权重无法在微调后**合并回预训练权重**，U-LoRA 推理时需额外计算，延迟增加约 1.39×。
  - 这是动态、不可合并方法的固有权衡，作者也承认这一限制，并指出此类方法的效率仍是开放问题；提出的 kernel fusion、量化等优化只能降低常数项，无法消除结构性开销。
- **实验覆盖可能仍有限**：
  - 数学推理仅使用 Math10K 作为训练源，可能偏向 GSM8K/AQuA 风格；未见更广泛的下游任务（如生成、对话、代码等）。
  - 未与其他动态 LoRA 类别（如 MoE-LoRA 系列更多变体）全面比较，但已有代表性基线。
- **潜在偏差风险**：
  - U-LoRA 参数量略高于同 rank 标准 LoRA（门控参数），虽与更高 rank LoRA 或 TopLoRA 进行了比较，但严格同参数量下的对比仍可进一步细化。
  - β 默认值 0.99 不是所有任务最优（最佳约 0.995），说明对超参数有一定敏感性，但敏感性总体中等。
- **方法适用范围**：主要面向 Transformer 线性层 LoRA 适配，对于非 Transformer 或特殊线性层结构可能需要调整；序列级聚合在 decoder 中使用 causal mask，在 encoder 中则使用双向上下文，行为差异未展开讨论。
