## 摘要
自注意力使大语言模型能够对上下文进行细粒度且依赖查询的访问，但稠密的 token 交互导致平方级预填充成本以及随上下文长度增长的键值缓存。因此，研究涵盖显式记忆压缩、稀疏访问、循环状态构建、结构化状态动态和异构机制组合。本综述将这些发展作为模型内部的上下文记忆加以分析。我们引入一个五维视角——记忆表示、记忆更新、访问、读出与整合——分别描述了什么被表示、如何变化、什么可被查询、如何被读取，以及读出如何形成输出。该视角在不强加单一计算模型的情况下比较相互重叠的研究脉络。

我们利用来自 14 个主要模型谱系和 11 个高性能开放权重端点的 59 条发布级记录，重建了机制层面的发展和架构采用情况。首先，显式记忆方法与循环状态方法保留了不同的接口，但越来越多地控制重叠的记忆功能。其次，异构架构越来越多地在网络深度上协同：逐层组合将互补的记忆处理分布到不同表征阶段，而跨层复用则将选定的记忆和路由产物向前传递。因此，深度成为上下文记忆被构建和管理的一个维度。第三，这些发展推动了一个有状态的多维记忆路由假说：持久记忆在时间范围、网络深度、基质类型和表征粒度上被组织，而协调的稀疏写入与稀疏读取决定了什么被维护以及什么对每个查询做出贡献。总体而言，高效的序列架构设计越来越关注上下文记忆的组织、生命周期和选择性使用，而不是孤立的注意力算子。

## Abstract
Self-attention gives LLMs fine-grained, query-dependent access to context, but dense token interactions incur quadratic prefill cost and a key--value cache growing with context length. Research thus spans explicit-memory compression, sparse access, recurrent state construction, structured state dynamics, and heterogeneous mechanism composition. This survey analyzes these developments as model-internal contextual memory. We introduce a five-dimensional lens---Memory Representation, Memory Update, Access, Readout, and Integration---describing what is represented, how it changes, what is query-eligible, how it is read, and how readouts form outputs. This lens compares overlapping research lines without imposing one computational model.   We reconstruct mechanism-level developments and architectural adoption using 59 release-level records from 14 major model lineages and 11 high-performing open-weight endpoints. First, explicit-memory and recurrent-state methods retain distinct interfaces but increasingly control overlapping memory functions. Second, heterogeneous architectures increasingly coordinate across network depth: layer-wise composition distributes complementary memory processing across representational stages, while cross-layer reuse carries selected memory and routing artifacts forward. Depth thus becomes a dimension along which contextual memory is constructed and managed. Third, these developments motivate a stateful multidimensional memory-routing hypothesis: persistent memory is organized across temporal scope, network depth, substrate type, and representation granularity, while coordinated Sparse Write and Sparse Read determine what is maintained and what contributes to each query. Overall, efficient sequence architecture design increasingly concerns the organization, lifecycle, and selective use of contextual memory rather than an isolated Attention operator.

# 论文核心问题与整体含义

- 自注意力为 LLM 提供了细粒度、依赖查询的上下文访问能力，但其稠密 token 交互带来两个主要成本：

# 论文提出的方法论

- 核心思想：将各类注意力与序列混合机制都视为**模型内部上下文记忆系统**，而不是孤立的计算算子。
- 提出**五维分析透镜**，用于比较不同机制对上下文记忆的处理：
  1. **Memory Representation（记忆表示）**：过去哪些信息仍被保留，以何种形式、粒度和容量存在。
  2. **Memory Update（记忆更新）**：当前输入如何添加、修改、压缩或覆盖已有记忆。
  3. **Access（访问）**：哪些已表示的信息有资格参与当前查询。
  4. **Readout（读出）**：对被访问的信息如何加权、解码或聚合。
  5. **Integration（整合）**：一个或多个已完成读出如何被变换、门控或融合为模块输出。
- 形式化表示：
  - 记忆模式 \( \rho \) 定义状态空间 \( M_t \in M_\rho \)；
  - 更新：\( M_t^+ = \mathrm{Update}_\rho(M_t^-, x_t) \)；
  - 访问：\( C_t = \mathrm{Access}_\rho(q_t, \hat{M}_t) \)；
  - 读出：\( r_t = \mathrm{Readout}_\rho(q_t, C_t) \)；
  - 整合：\( o_t = \mathrm{Integration}_\rho(r_t; x_t) \)。
- 该框架不是强制五阶段计算图，而是功能角色；同一操作可能同时影响多个维度。
- 分类原则：将研究线分为四类机制中心（Softmax Attention、Sparse Attention、Linear Attention、State Space Models）和一类组合中心（Hybrid Architecture），并强调这些类别不是互斥划分。

  - **纵向清单**：59 条发布级架构记录，覆盖 14 个主要模型谱系，时间从 2022 年至 2026-09-22。
  - **横向截面对比**：基于 Artificial Analysis Intelligence Index v4.3.2 快照，选取 11 个高性能开放权重模型端点。
- 三层综合：
  1. 机制层：显式记忆与循环状态两条路线接口不同，但控制范围越来越重叠；
  2. 架构层：逐层组合与跨层复用使网络深度成为记忆组织的新维度；
  3. 未来假说：**有状态多维记忆路由（Stateful Multidimensional Memory Routing）**，在时间范围、网络深度、基质类型、表示粒度四个坐标上组织持久记忆，并由协调的 Sparse Write 和 Sparse Read 控制。

# 论文的主要结论与发现

- **注意力设计没有收敛为单一标准**：
  - GQA、MLA、Sparse Attention、循环状态、SSM 等路线持续共存；
  - 生产线如 DeepSeek、Qwen、MiniMax、LongCat 都在各自谱系内改变过架构方向，而非单调演进。
- **机制层面的综合**：
  - 显式记忆路线与状态循环路线保留了不同的记忆接口；
  - 但二者都在向更广的记忆功能控制范围扩展：显式记忆方法开始控制更新、读出与整合，状态方法开始控制多个状态单元、访问、读出与整合；
  - 结论表述为“控制范围趋同，而非记忆基质或算子趋同”。
- **架构层面的综合**：
  - 异构 Hybrid 架构越来越常见，主要组织方式仍是预定义逐层调度；
  - 跨层复用开始出现：共享 KV 表示、索引状态或候选决策，使记忆产物的生命周期跨深度延伸；
  - 网络深度由此成为上下文记忆组织的新兴维度。
- **未来假说**：
  - 提出状态化多维记忆路由：以时间范围、网络深度、基质类型、表示粒度为地址坐标；
  - Sparse Write 决定哪些记忆地址保留新信息；
  - Sparse Read 决定哪些被表示单元对当前查询做出贡献；
  - 写入路由会改变未来可用的记忆状态，因此这是一种“有状态路由”，而非单纯当前计算选择。
- **总体结论**：
  - 高效序列架构设计正从优化单个 Attention 算子，转向对上下文记忆的组织、生命周期和选择性使用的联合设计。
