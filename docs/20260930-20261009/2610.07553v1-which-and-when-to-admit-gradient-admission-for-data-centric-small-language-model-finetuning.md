## 摘要
LoRA 微调在低秩更新子空间内使小型语言模型（SLM）适应异构指令数据，这使其容易受到三个结构性问题的影响：相互冲突的梯度相互抵消、静态数据选择无法跟踪不断变化的学习动态，以及子空间饱和导致后续更新覆盖有用方向。我们认为，有效的适配因此需要控制哪些数据诱导的梯度进入 LoRA 子空间以及何时进入。我们提出 GRADE（梯度对齐的以数据为中心配方，GRadient-Aligned Data-centric rEcipe），一个以数据为中心的框架，结合了两种机制：一个状态感知的选择器，持续准入与不断演化的多任务梯度场对齐的样本；以及一个自校准的步级门控，拒绝在接近饱和时可能造成破坏性覆盖的更新。在三个当前一代骨干模型和一个异构的七数据集指令池上，GRADE 在准确性和鲁棒性方面优于强大的数据选择和 PEFT 稳定化基线。它是唯一一种在每种架构上都持续优于标准 LoRA 的方法，同时产生更连贯的梯度轨迹和更少的破坏性覆盖。这些结果表明，成功的 SLM 适配不仅取决于选择了哪些数据，还取决于允许哪些梯度进入并持久存在于受限更新子空间中。

## Abstract
LoRA fine-tuning adapts small language models (SLMs) to heterogeneous instruction data within a low-rank update subspace, making it vulnerable to three structural problems: conflicting gradients that cancel, static data selection that cannot track evolving learning dynamics, and subspace saturation that causes later updates to overwrite useful directions. We argue that effective adaptation therefore requires controlling which data-induced gradients enter the LoRA subspace and when. We propose GRADE (GRadient-Aligned Data-centric rEcipe), a data-centric framework combining two mechanisms: a state-aware selector that continually admits samples aligned with the evolving multi-task gradient field, and a self-calibrating step-level gate that rejects updates likely to cause destructive overwrite near saturation. Across three current-generation backbones and a heterogeneous seven-dataset instruction pool, GRADE outperforms strong data-selection and PEFT-stabilization baselines in accuracy and robustness. It is the only method to improve consistently over standard LoRA on every architecture, while producing more coherent gradient trajectories and less destructive overwrite. These results show that successful SLM adaptation depends not only on which data are selected, but also on which gradients are allowed to enter and persist in the constrained update subspace.

## 1. 论文的核心问题与整体含义

- **研究背景**：小型语言模型（SLM）通常通过 LoRA 微调适应异构指令数据，但该过程在低秩子空间中容易出现不稳定：
  - **梯度冲突**：不同任务/数据集的更新方向互相抵消。
  - **状态不匹配**：一次性数据选择无法跟随模型状态演化。
  - **子空间饱和**：后期更新会覆盖先前有用的低秩方向。
- **核心论点**：有效 LoRA 微调不应只关注“选择哪些数据”，更应关注“哪些数据诱导的梯度被允许进入低秩子空间，以及何时提交更新”。
- **整体含义**：将数据为中心的 LoRA 微调从“无条件梯度累积”转变为“受控梯度准入”，以提升跨架构的准确性和鲁棒性。

## 2. 论文提出的方法论

GRADE（GRadient-Aligned Data-centric rEcipe）包含两个耦合机制：

- **状态感知、梯度对齐的样本选择（Mechanism 1）**
  - 每个训练步，对候选样本进行前向探针评分：沿 LoRA 子空间中随机单位方向 `u` 加扰动 `ϵ`，计算样本的方向导数 `d_i`，并与参考集 `Dref` 的方向导数 `d_ref` 做内积，得到对齐分数 `a_i = d_i · d_ref`。
  - 该分数是无偏估计梯度内积 `(1/q) g_i^T g_ref`（`q` 为 LoRA 子空间维度）。
  - 每个 mini-batch 选择 top-`k_b` 样本；保留比例 `r*` 通过训练池梯度几何在 `t=0` 时解析计算：
    \[
    r^* = \frac{\cos_{\text{intra}}}{\cos_{\text{intra}} + (T-1)\cos_{\text{inter}}}
    \]
    其中 `T` 为数据集数量，`cos_intra` 为数据集内平均梯度余弦，`cos_inter` 为跨数据集平均梯度余弦。
  - 该规则使选择强度与池的梯度协方差结构自动适配，无需手动调参。

- **自校准的步级更新准入门控（Mechanism 2）**
  - 基于一阶损失下降恒等式 `L(t+1) - L(t) ≈ -η ||G_LoRA||²`，用已选批次的探针损失 `L_probe` 及其指数移动平均（EMA）判断当前更新是否仍有建设性。
  - 初始阶段门控关闭，标准 LoRA 全量提交；当相对斜率 `(L_prev - L_cur)/L0` 低于阈值 `ε_rel` 时，门控打开（latch）。
  - 打开后，若当前 `L_probe > EMA`，则跳过本次优化器更新（SKIP），否则执行基础 LoRA 更新。
  - 在稳态噪声下，跳过比例自然接近 0.5；门控无额外可学习参数，仅依赖损失轨迹比较。

- **闭环耦合**：样本选择决定进入子空间的梯度，门控决定更新是否提交，提交后的模型状态又影响下一轮选择评分。

## 6. 论文的主要结论与发现

- **GRADE 总体优势**：在 3 个骨干上，GRADE 是唯一实现严格正的 Worst-Δ（+0.18 pp）且 Mean-Δ 最高（+0.99 pp）的方法，而所有基线在至少一个架构上均出现退化。
- **选择机制**：梯度对齐选择将梯度流相干性比率提升约 5 倍，抑制了低秩子空间内的破坏性干扰；它不是简单的数据集重加权或难度过滤，而是方向兼容性过滤。
- **门控机制**：步级门控在训练早期自动打开，稳态跳过比例接近理论预测的 0.5；关闭门控在所有骨干上均降低准确率（+0.04 至 +0.38 pp）。
- **耦合必要性**：仅选择或仅门控都无法消除跨架构退化，二者联合控制梯度形成与持久化才实现一致非退化。
- **整体结论**：异构 LoRA 微调的核心是结构化梯度准入问题；先提升学习信号几何，再控制其时间持续性，可将不稳定累积转换为受控准入。

## 7. 优点

- **视角新颖**：将数据选择问题重新定义为梯度准入问题，提出样本级和步级双重控制。
- **方法轻量**：前向探针避免额外反向传播，保留比例解析推导，门控无额外参数，兼容现有 LoRA 参数化。
- **实验强劲**：覆盖多个骨干和基线，结果一致且非退化；机制分析深入，排除多种替代解释（如早停、步数、LR 调参）。
- **理论支撑充分**：提供无偏梯度内积估计证明、一阶损失下降恒等式推导、闭合形式保持率推导。
- **可解释性**：通过梯度相干性、选择轨迹、门控动态等多维证据解释机制。

## 8. 不足与局限

- **计算代价**：额外前向探针增加约 1.3–1.5 倍 wall-clock；门控本身不节省计算，仅提升每步质量。
- **模型规模有限**：仅在 8–9B 量级骨干上验证，未扩展至更大模型或更多任务。
- **任务与数据范围**：训练池为 7 个特定数据集，评测仅三任务；更广泛基准（MMLU、BBH、TruthfulQA 等）仅作为未来承诺，实际报告不充分。
- **前向探针精度**：前向探针与精确梯度的相关性较低，方法更像结构化正则化而非精确梯度估计；精确梯度仍优于探针。
- **超参数敏感性与迁移性**：虽然 keep rate 和门控大多自适应，但学习率需要按骨干选择；附录中部分敏感性实验为计划状态，未完全验证。
- **特定假设**：异构池前提是实验设计的一部分，若任务同质或噪声少，选择机制收益可能有限；门控基于训练损失轨迹，可能受批次成分影响。
- **公平性细节**：ClusterUCB 复现结果与 LoRA 完全相同（+0.00），可能提示复现或实现问题；部分架构校准（如 Qwen3-8B 学习率）需额外说明。
