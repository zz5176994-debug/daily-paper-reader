## 摘要
基于大语言模型（LLM）的多智能体系统日益依赖记忆将执行轨迹转化为可复用的程序性知识。然而反复检索也使记忆错误持续存在：当过时、支持不足或偶然成功的程序成为未来推理中反复出现的组成部分时，就会产生记忆污染。多智能体执行还引入了额外的结构性风险。当程序性知识脱离其被证明有效的协调范围，并在不兼容的决策层级被反复复用时，就会发生范围坍塌，导致局部错误影响级联的下游决策。与此同时，任务级失败提供的监督信息是模糊的，因为它们很少揭示哪条被召回的知识是原因。我们提出AECG，一个面向多智能体系统的非对称经验整合与治理框架。AECG将记忆从静态经验存储转变为动态的可靠性治理循环，保持协调范围，并利用多尺度、置信度感知的可靠性来检测退化。随后，它将退化与下游影响相结合，在有限的审查预算下优先处理高风险知识，应用针对性干预，并仅在成对重放后重新激活修订后的技能。在三个多智能体框架和四个基准上，AECG在12个框架-基准设置中的11个取得了最佳分数，并且相比最强的竞争记忆方法最多提高10.23个百分点；移除范围保持会使准确率最多下降16.89个百分点。因此，AECG将多智能体记忆从被动积累重新定位为可审计的可靠性治理。代码可在https://github.com/fenhg297/AECG获取。

## Abstract
Large language model (LLM)-based multi-agent systems increasingly rely on memory to transform execution trajectories into reusable procedural knowledge. Yet repeated retrieval also makes memory errors persistent: memory pollution arises when outdated, weakly supported, or spuriously successful procedures become recurring components of future reasoning. Multi-agent execution introduces an additional structural risk. Scope collapse occurs when procedural knowledge escapes the coordination scope in which it was shown effective and is repeatedly reused at incompatible decision levels, allowing local errors to influence cascades of downstream decisions. Meanwhile, task-level failures provide ambiguous supervision because they rarely reveal which recalled knowledge was responsible. We introduce AECG, a framework for asymmetric experience consolidation and governance for multi-agent systems. AECG turns memory from static experience storage into a dynamic reliability-governance loop, preserving coordination scope and using multi-scale, confidence-aware reliability to detect degradation. It then combines degradation with downstream impact to prioritize high-risk knowledge under a bounded review budget, applies targeted interventions, and reactivates revised skills only after paired replay. Across three multi-agent frameworks and four benchmarks, AECG achieves the best score in 11 of 12 framework--benchmark settings and improves over the strongest competing memory method by as much as 10.23 percentage points; removing scope preservation reduces accuracy by up to 16.89 points. AECG thereby reframes multi-agent memory from passive accumulation into auditable reliability governance. Code is available at https://github.com/fenhg297/AECG

## 1. 论文的核心问题与整体含义

- **研究背景**：基于大语言模型（LLM）的多智能体系统越来越依赖记忆，将执行轨迹转化为可复用的程序性知识（技能）。但反复检索会让记忆错误持续存在，形成“记忆污染”：过时、弱支持或偶然成功的程序成为未来推理的固定组成部分。
- **核心问题**：
  - 多智能体执行引入“范围坍塌”（scope collapse）：程序性知识脱离其被证明有效的协调范围，在不兼容的决策层级被反复复用，使局部错误影响下游级联决策。
  - 任务级失败提供的监督非常模糊：很少能指出是哪一条被召回的知识导致了失败。
- **整体含义**：现有方法侧重于知识如何形成和召回，却忽略了持续复用下可靠性的衰减。AECG 将多智能体记忆从“被动积累”重构为“可审计的可靠性治理”，形成一个动态的治理闭环。

## 2. 论文提出的方法论

AECG 框架包含四个核心部分：

- **范围保持的证据生命周期（Scope-Preserving Evidence Lifecycle）**
  - 将每个执行节点映射到协调范围：`TEAM`（团队级规划）、`EVENT(e)`（协作事件）、`AGENT(e,a)`（角色特定执行）。
  - 程序性记忆 `m` 抽象为技能 `k` 时强制 `s(k)=s(m_seed)`，防止跨范围重用。
  - **非对称证据准入**：成功轨迹提供置信度加权的正证据；失败轨迹默认标记为“未解决”负证据，只有通过双 LLM 法官保守归因门控（两者识别同一技能、同一范围、均不弃权、平均置信度≥0.70）才被接纳为负证据，否则保留为 BadCase 但不更新可靠性。
  - **技能形成与证据继承**：同一范围内有足够支持的程序性记忆通过 readiness 规则提升为技能，继承来自种子证据的折扣伪计数（慢状态全保留，快状态带窗口上限）。

- **双时间尺度可靠性估计（Dual-Timescale Reliability Estimation）**
  - 每个技能版本维护两个 Beta 风格伪计数信念：慢信念（累积历史）和快信念（折扣近期）。
  - 对每个被接纳的观测更新信念：`b = b0 + λ(b_prev - b0) + c·e(y)`，其中慢信念 `λ=1`，快信念 `λ<1`。
  - 定义当前失败风险 `R_fail = 1 - μ_F`，均值级退化 `D = [μ_S - μ_F]+`，以及不确定性感知的漂移分数 `R_drift`（通过蒙特卡洛采样并减去噪声基线）。
  - 慢/快信念区分“一直不可靠”和“近期相对自身历史退化”两种技能。

- **风险与暴露感知的记忆治理（Risk- and Exposure-Aware Governance）**
  - **暴露感知预算分诊**：对每次技能使用，计算其下游暴露 `e_obs = Σ γ^{dist-1}`（γ=0.5，距离折扣），融合近期平均暴露与使用频率得到 `E_k`；只有置信度门控 `C_deg ≥ η_deg` 且 `R_drift>0` 的技能才进入候选，按 `H_k = E_k · R_drift` 排名，在固定预算 `B_review` 内选取审查。
  - **证据路由干预**：根据合格失败证据选择干预类型——`NARROW`（收窄适用上下文，不改程序）或 `REPAIR`（修复程序缺陷，保留范围与意图）；如无充分证据则不生成候选。
  - **重放门控激活**：生成版本化候选而非覆盖活性技能。候选必须同时满足：在失败夹具上缓解故障，在历史成功夹具上保持性能（回归容差 ε_reg=0.05）才能激活；否则继续监测或隔离（依据快信念置信度）。
