## 摘要
大型推理模型（LRM）通过扩展推理提升复杂任务表现，但同一过程可能退化为冗余验证和持续生成循环。这种失控推理增加了推理成本，并带来资源耗尽和服务降级的风险。然而，现有缓解手段主要截断长输出或对表面重复作出反应，因而无法区分正常思考与失控推理，也无法解释良性推理如何退化为有害行为。本文将大型推理模型的生成过程操作化为四种状态，并提出基于动态注意力响应的推理状态分析（RADAR），实时识别当前推理状态，刻画有效反思如何演变为失控生成。在 RADAR 分析的指导下，我们进一步将异常注意力分布重新对齐到正常请求中所观察到的模式，并考察这种修正如何影响过度反思和持续循环。时间分析表明，失控推理的特征是注意力分布偏离正常生成，且异常趋势在重复开始前即可被检测到。通过注意力重新对齐来纠正这些偏差，能够持续减少循环，同时大体保持良性性能。总之，RADAR 对推理如何变得失控提供了机制性解释，为识别关键失败阶段和设计有针对性的运行时干预提供了可操作的指导。

## Abstract
Large reasoning models (LRMs) improve performance on complex tasks through extended reasoning, yet the same process can degenerate into redundant verification and persistent generation loops. Such uncontrolled reasoning increases inference cost and creates risks of resource exhaustion and service degradation. However, existing mitigations largely truncate long outputs or react to surface repetition, and thus fail to distinguish normal thinking from uncontrolled reasoning or explain how benign reasoning degenerates into harmful behavior. In this paper, we operationalize LRM generation as four states and further introduce Reasoning-state Analysis via Dynamic Attention Responses (RADAR), which identifies the current reasoning state in real time and characterizes how effective reflection can develop into uncontrolled generation. Guided by RADAR's analysis, we further realign abnormal attention distributions toward patterns observed in normal requests and examine how this correction affects excessive reflection and persistent looping. Temporal analyses show that uncontrolled reasoning is characterized by attention distributions that deviate from normal generation, with abnormal trends becoming detectable before repetition begins. Correcting these deviations through Attention Realignment consistently reduces looping while largely preserving benign performance. Together, RADAR provide a mechanistic account of how reasoning becomes uncontrolled, offering actionable guidance for identifying critical failure stages and designing targeted runtime interventions.

# 论文总结

## 1. 核心问题与研究动机

- 大型推理模型（LRMs）通过扩展推理链（reasoning traces）在复杂任务上取得显著性能提升，但同一机制可能退化为**冗余验证**和**持续生成循环**，导致推理成本激增、资源耗尽甚至服务降级。
- 现有缓解方法主要依赖**截断长输出**或**检测表面重复**，无法区分正常思考与失控推理，也无法解释良性推理如何逐步退化为有害行为。
- 因此，本文的核心问题是：**能否从注意力动态中实时识别推理状态，并据此对失控推理进行有针对性的干预**，从而在保留有效反思的同时抑制过度反思和循环。

## 2. 方法论

### 2.1 四种推理状态定义

论文将大型推理模型的生成过程操作化为四种状态（`S = {D, R, O, L}`）：

- **直接回答（D，Direct answering）**：单一路径直接给出最终答案，无显式反思或回溯，不论答案正确与否。
- **有效反思（R，Effective reflection）**：包含 1–5 次有实质进展的修正或再考虑，最终给出确定答案。
- **过度反思（O，Excessive reflection）**：在已有充分答案后仍持续重新考虑，语义上反复变化但几乎不提供新信息。
- **持续循环（L，Persistent looping）**：重复输出相同或近似内容，无实质进展，且在生成上限内无法自然终止。

### 2.2 RADAR：动态注意力响应分析

RADAR（Reasoning-state Analysis via Dynamic Attention Responses）通过两个互补的注意力测量来刻画当前推理状态。

#### 2.2.1 注意力测量

- **Prompt Attention Share（PAS）**  
  计算当前 token 在每一层对原始提示（prompt）区域的注意力占比，并对所有层取平均。PAS 越高，表明模型越关注输入提示；越低，表明越关注已生成的内容。公式为：  
  \( M_P(s) = \mathbb{E}_{l \in \{1,\dots,L\}} \left[ \sum_{j=p}^{s} A^{(l)}_{s,j} \right] \)，其中 \(p\) 为提示长度，\(s\) 为当前序列长度。

- **Cross-context Token Similarity（CTS）**  
  对提示区域和生成区域中出现的相同 token 身份，比较其在两个区域内部的注意力分布相似度（total-variation similarity），并在所有层上取平均。CTS 越高，说明相同 token 在提示和生成上下文中的注意力分配越一致。

#### 2.2.2 时序状态推断分类器

- 对每个生成前缀，提取三个特征：
  1. **PAS 趋势**：对 PAS 历史序列拟合最小二乘直线，取其斜率。
  2. **平均 CTS 水平**：当前前缀内 CTS 的均值。
  3. **生成进度**：当前生成长度的对数（\(\log k\)）。
- 对特征进行标准化后，使用 softmax 回归（加权负对数似然 + L2 正则化）输出四种状态的概率分布。
- 训练时，每个前缀继承其完整轨迹的标签；在线推理时，在几何间隔的序列长度（2 的幂次）处执行状态推断。

### 2.3 注意力重对齐（Attention Realignment）

当在线分类器预测为 O 或 L 且置信度超过阈值 \(\tau\) 时，激活注意力重对齐干预：

- **层选择**：保留训练集中 PAS 均值最高的前 \(\lceil \xi L \rceil\) 层作为候选层；再筛选当前 CTS 低于阈值 \(\kappa_C\) 的层，得到实际干预层。
- **PAS 重平衡**：根据正常轨迹（D/R）拟合 PAS 随生成长度和提示长度的参考曲线，将当前 PAS 调整到正常范围。
- **CTS 抑制**：对生成侧注意力高于提示侧的 token 身份进行抑制，将释放的注意力质量重新分配给其余生成 token，使同 token 在提示和生成区域的注意力分布趋向一致。

## 6. 主要结论与发现

- **状态诊断**：RADAR 在五个模型上平均 micro-F1 达到 **89.8%**，能较准确区分四种推理状态。
- **时序特征**：直接回答（D）置信度快速上升后稳定；有效反思（R）早期即可识别；过度反思（O）从早期就高置信度且持续稳定；持续循环（L）逐渐显现。在自然诱导攻击中，中等置信度（≤0.5）阈值通常能在重复开始前检测到异常。
- **注意力机制**：
  - 正常状态（D/R）的 PAS 随生成长度上升，且 D 的 PAS 高于 R。
  - 过度反思（O）PAS 高且稳定；持续循环（L）PAS 逐渐向生成内容偏移。
  - 良性状态 CTS 明显高于失控状态（O/L），提示失控推理伴随更严重的提示-生成注意力不对称。
- **干预效果**：注意力重对齐将五个模型的平均最终循环率从 **37.0% 降至 27.2%**（降低 9.8 个百分点），同时良性任务准确率平均提升 4.0 个百分点（仅在 Llama-8B 上下降 0.8 个百分点）。

## 7. 优点

- **机制性视角**：不是简单截断或检测表面重复，而是从注意力动态出发，解释推理如何从有效反思演变为失控行为。
- **四状态细粒度诊断**：区分过度反思（语义变化）和持续循环（词法重复），避免将所有长推理视为有害。
- **可操作的运行时干预**：根据状态置信度有选择地触发注意力重对齐，在抑制失控的同时基本不影响正常推理。
- **跨模型泛化**：在五个不同架构的推理模型上均取得一致的诊断和干预效果。
- **丰富的分析**：提供检测时机、PAS/CTS 轨迹、层选择敏感性等消融，增强结果可信度。

## 8. 不足与局限

- **自然失控推理覆盖不足**：论文主要评估目标性攻击（Recur、LoopLLM、MiP 等），对自然发生的局部循环或过度反思没有系统实验，承认自发性故障难以大规模收集。
- **防御对比不完整**：AUSteer 和 n-gram 对比只在单一模型上进行，跨模型防御性能缺乏对比。
- **计算开销**：在线提取 PAS/CTS 并进行分类和注意力修正需要访问注意力张量，可能增加推理延迟；论文未量化该开销。
- **层选择和超参数依赖**：注意力重对齐涉及多个超参数（\(\tau, \xi, \kappa_C\)），需针对模型调优，通用性受限。
- **边界情况处理**：CTS 在提示-生成无共享 token 时取值为 1，虽未在实验中观察到，但理论上可能影响极端输入下的判断。
- **某些攻击的不一致性**：例如 Recur 在 GLM-4.7-Flash 上未产生输出级循环，但分类器仍标记为 O，解释为捕捉到内部过度反思特征，这可能对评测标准带来一定模糊性。
