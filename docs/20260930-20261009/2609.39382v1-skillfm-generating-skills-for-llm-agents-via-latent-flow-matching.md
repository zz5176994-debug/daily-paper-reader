## 摘要
文本技能为大型语言模型智能体提供可复用的指导，但现有方法通常依赖人工整理的技能库或具有间接且延迟反馈的强化学习。我们提出 SkillFM（Skill Flow Matching），一个生成式框架，它直接合成以任务为条件的文本技能，无需测试时技能检索。该框架将用于在连续潜在空间中编码和重建文本技能的编解码器，与使用改进的 MeanFlow 训练的条件流模型相结合。在推理时，学习到的速度场支持单步潜在采样，基于 LLM 的解码器将采样得到的表示转换为针对冻结下游智能体的文本指导。我们在具身任务、问答和网上购物上评估了该框架。在 ALFWorld 和 Search-QA 上，我们的方法在比较的基于向量的技能方法中取得了最佳整体性能。我们的分析进一步表明，潜在技能生成是基于检索的技能增强的有效替代方案。我们的代码和训练技能库可在 https://github.com/lulushang999/SkillFM 获取。

## Abstract
Textual skills provide reusable guidance for large language model agents, but existing approaches often rely on manually curated skill banks or reinforcement learning with indirect and delayed feedback. We introduce SkillFM (Skill Flow Matching), a generative framework that synthesizes task-conditioned textual skills directly without test-time skill retrieval. Our framework combines a codec for encoding and reconstructing textual skills in a continuous latent space with a conditional flow model trained using improved MeanFlow. At inference time, the learned velocity field enables single-step latent sampling, and an LLM-based decoder converts the sampled representation into textual guidance for a frozen downstream agent. We evaluate the framework on embodied tasks, question answering, and web shopping. On ALFWorld and Search-QA, our method achieves the best overall performance among the compared vector-based skill approaches. Our analyses further demonstrate that latent skill generation is an effective alternative to retrieval-based skill augmentation. Our code and training skill libraries are available at https://github.com/lulushang999/SkillFM.

## 1. 核心问题与整体含义

- 文本技能（textual skills）能够为大型语言模型（LLM）智能体提供可复用指导，但现有方法通常依赖：
  - 人工整理的技能库，需要精确的检索机制；
  - 强化学习，其反馈间接且延迟，难以判断技能应保留、修改还是丢弃。
- 技能库不断增长时，相关技能更难与冗余或误导性内容区分，维护成本高。
- 本文提出 **SkillFM（Skill Flow Matching）**，将技能获取从“检索 + 维护”转向“生成”。
- 核心思想：从离线技能库中学习任务到技能的映射，在测试时**直接生成任务条件的文本技能**，不再进行技能检索。
- 整体含义：为 LLM 智能体的技能自进化提供一种更简洁、可移植、鲁棒的替代方案。

## 2. 方法论

- **技能收集**：通过迭代执行与总结构建固定的任务–技能对 \((c, s)\)。执行器收集交互轨迹，总结器从成功尝试中提炼可复用程序；随后去重、清洗，形成训练库。
- **技能编解码器（Skill Codec）**：
  - 编码器 \(E_\phi\) 只读取技能文本，输出单位球面上的隐向量 \(z \in \mathbb{R}^d\)，其中 \(d=2560\)。
  - LayerNorm–线性投影器 \(P_\psi\) 将 \(z\) 映射为 \(K=16\) 个连续前缀嵌入。
  - 任务条件自回归解码器 \(D_\omega\) 从前缀嵌入和任务条件 \(c\) 重建技能文本。
  - 使用球面扰动增强 \(\tilde{z} = \cos(\alpha)z + \sin(\alpha)v\)（\(v \perp z\)）使解码器暴露于邻近隐码。
  - 训练损失为负对数似然重建损失，仅对技能 token 和终止符计算损失。
- **条件流训练（Conditional Flow Matching）**：
  - 冻结编解码器和独立查询编码器。
  - 缩放数据端点 \(x = \sqrt{d} E_\phi(s)\)，使其范数与高斯噪声匹配；查询编码 \(q = E_{\text{query}}(c)\)。
  - 构造线性插值 \(x_t = (1-t)x + t\epsilon\)，其中 \(\epsilon \sim \mathcal{N}(0, I_d)\)。
  - 条件 Transformer \(u_\theta(x_t, r, t, q)\) 预测区间平均速度。
  - 采用 **改进 MeanFlow** 目标：利用对角线评估 \(b_\theta = u_\theta(x_t, t, t, q)\) 估计瞬时速度；导数校正为 \(D_t u_\theta = \partial_t u_\theta + (J_{x_t}u_\theta)b_\theta\)；复合预测 \(V_\theta = u_\theta(x_t, r, t, q) + (t-r)\text{stopgrad}(D_t u_\theta)\)；优化加权 L2 损失。
- **技能引导执行**：
  - 新任务下，采样 \(y_1 \sim \mathcal{N}(0, I_d)\)，单步流估计 \(y_0 = y_1 - u_\theta(y_1, 0, 1, q)\)，归一化得到 \(\hat{z} = y_0/\|y_0\|_2\)。
  - 冻结解码器生成技能文本；冻结执行器按 \(a_k \sim \pi_{\text{actor}}(\cdot | c, \hat{s}, h_k)\) 行动。
  - 每个任务仅生成一次技能，测试时无技能库查找，**NFE = 1**。

## 6. 主要结论与发现

- SkillFM 在 ALFWorld 和 Search-QA 上取得所比较向量技能方法中的最佳整体性能：
  - ALFWorld：seen 82.14%，unseen 84.33%，总 83.21%，分别超过 LatentSkill 约 7.8 和 14.9 个百分点。
  - Search-QA：微平均 EM 从 35.62% 提升至 39.36%。
  - WebShop：20.00% SR，得分 55.35，超过 8 个提示/记忆基线中的 7 个。
- **潜在技能生成是检索式技能增强的有效替代方案**：
  - 在 25% 无关技能噪声下，生成式指导优于嵌入检索（ALFWorld、Search-QA、WebShop 均有提升）。
- 训练规模和技能质量：
  - 高质量技能库下，500→1000 条训练技能仅带来小幅提升，说明少量高质量技能即可学习有效生成。
  - 当 75% 源轨迹成功时，扩大技能库可缓解部分质量下降。
- 消融显示：编解码器训练和流推理都对性能有显著贡献；仅解码器监督微调效果远差于完整方法。
